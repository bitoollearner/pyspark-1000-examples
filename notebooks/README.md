# Chapter notebooks

22 Jupyter notebooks live here — one per chapter — each containing all the
book's examples for that chapter as runnable code cells.

**These files are generated** by running (from repo root):

```bash
python scripts/generate_notebooks.py <path-to-book-folder>
```

After generation, this folder will contain:

- `01-introduction.ipynb` — Chapter 1 (20 examples)
- `02-session.ipynb` — Chapter 2 (30 examples)
- ...
- `22-patterns.ipynb` — Chapter 22 (~45 examples)

Total: **1,000 runnable examples** across 22 notebooks.
